# Takkar for Android (beta)

**Roz ek takkar.** A four-minute daily quiz duel for SSC, banking and railway aspirants aged 18 and over: ten Quant and Reasoning questions, exam-style marking, a rival, squads with friends and step-by-step solutions. No cash prizes and no betting, ever.

This repository only hosts the Android downloads. The app's source code is private.

## Download

**[Download the latest version](https://github.com/dharmendra3840/takkar-app/releases/latest/download/Takkar-beta.apk)** (Android 6.0 or newer), or see every version under [Releases](https://github.com/dharmendra3840/takkar-app/releases).

Install steps and the file's SHA-256 fingerprint are on [playtakkar.in/beta](https://www.playtakkar.in/beta). You can also play in any browser at [playtakkar.in/play](https://www.playtakkar.in/play/), with no download.
